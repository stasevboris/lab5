# ЛР5 — нейронная сеть Хопфилда

## Сеть Хопфилда

**Вариант 1 — описание метода.** Сеть Хопфилда — рекуррентная нейронная сеть, используемая как ассоциативная память. Бинарные образы кодируются значениями −1 и +1, веса вычисляются по правилу Хебба, самосвязи обнуляются. При восстановлении нейроны обновляются по знаку взвешенного влияния остальных. Обновление может быть синхронным или последовательным. В асинхронном режиме энергия симметричной сети не возрастает, однако устойчивый результат не обязательно совпадает с нужным эталоном.

**Вариант 2 — простыми словами.** Сеть запоминает, как обычно расположены чёрные и белые клетки в трёх буквах. Когда показываем испорченную букву, каждая клетка получает подсказку от остальных и меняет своё значение. Постепенно рисунок перестаёт изменяться. Обычно при небольшом шуме получается нужная буква, но иногда сеть останавливается на неправильном устойчивом рисунке.

**Фрагмент реализации на Python:**

```python
WEIGHTS = PATTERNS.T @ PATTERNS
np.fill_diagonal(WEIGHTS, 0)

fields = WEIGHTS @ state
for neuron in order_rng.permutation(len(state)):
    updated = 1 if fields[neuron] > 0 else -1
    delta = updated - state[neuron]
    if delta:
        state[neuron] = updated
        fields += delta * WEIGHTS[:, neuron]
```
