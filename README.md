# Лабораторная работа 5. Нейронная сеть Хопфилда

Запоминание букв С, Т, А размером 10×10 и восстановление при разных уровнях шума.

Основной файл: [ЛР5_сеть_Хопфилда_Стасев.ipynb](<ЛР5_сеть_Хопфилда_Стасев.ipynb>).

## Запуск в Jupyter

```sh
python -m pip install -r requirements.txt
python -m pip install jupyterlab
python -m jupyterlab
```

Откройте ноутбук и выполните **Kernel → Restart Kernel and Run All Cells**. Данные находятся в ячейках; дополнительных файлов не требуется.

## Запуск в Google Colab

Скачайте `.ipynb` из этого репозитория и загрузите его через **Файл → Загрузить блокнот**. Затем выберите **Среда выполнения → Выполнить всё**.

Ноутбук содержит исходные данные, объяснение алгоритмов, таблицы, графики и ячейку с проверками. Параметры экспериментов вынесены отдельно. Результаты вычисляются кодом при запуске.
