# ЛР5 — сеть Хопфилда простыми словами

## Что нужно найти

Сеть должна запомнить буквы С, Т и А, а потом восстановить их по испорченным изображениям.
Каждая буква — сетка 10×10, то есть 100 пикселей. Один пиксель соответствует одному нейрону.

## 1. Превращаем картинку в числа

```python
PATTERNS = np.array([[1 if pixel == '#' else -1 for row in LETTERS[name] for pixel in row]
                     for name in LETTER_NAMES], dtype=np.int64)
```

В `LETTERS` буквы нарисованы символами: `#` — чёрная клетка, точка — белая.
Выражение `1 if pixel == '#' else -1` заменяет чёрную клетку на +1, белую на −1.
Циклы внутри списка проходят по буквам, строкам и клеткам. В итоге `PATTERNS` — таблица из трёх строк по 100 чисел.

Нейрон здесь не сложный объект: это одно число +1 или −1, которое может измениться при восстановлении.

## 2. Запоминаем буквы через веса связей

```python
WEIGHTS = PATTERNS.T @ PATTERNS
np.fill_diagonal(WEIGHTS, 0)
```

Первая строка считает связи между каждой парой пикселей по всем трём буквам. Это правило Хебба.
Если два пикселя в образе одинаковы, их произведение равно +1; если различаются — −1. Такие произведения складываются по образам.
Так сеть сохраняет информацию о том, какие пиксели обычно должны быть согласованы.

`.T` разворачивает таблицу, меняя строки и столбцы местами. `@` перемножает матрицы.
Получается матрица 100×100: вес связи каждого нейрона с каждым.
Вторая строка ставит на диагонали нули, чтобы нейрон не влиял на себя собственной связью.

## 3. Определяем новое состояние нейрона

```python
def activation(field):
    return np.where(field > 0, 1, -1)
```

`field` — суммарное влияние остальных нейронов с учётом весов.
Если оно положительное, ставим +1; если нулевое или отрицательное — −1.
`np.where` выполняет такое правило сразу для набора нейронов.

Можно представить это как взвешенное голосование соседних пикселей: они подсказывают, какой должна быть клетка.

## 4. Синхронно обновляем все нейроны

Внутри `recall_sync()`:

```python
updated = activation(WEIGHTS @ state)
if np.array_equal(updated, state):
    return RecallResult(updated, step, 'Устойчивое состояние')
```

`WEIGHTS @ state` считает влияние на все нейроны по старому состоянию сети.
`activation()` одновременно выбирает новые значения всех ста клеток.
Если `updated` полностью совпал со `state`, картинка больше не меняется — возвращается устойчивое состояние.

Дополнительно словарь `seen` запоминает посещённые картинки. Если старая картинка повторилась, обнаружен цикл.
Например, сеть может бесконечно чередовать две картинки; это цикл длины 2.

## 5. Асинхронно обновляем нейроны по одному

Внутри `recall_async()`:

```python
for neuron in order_rng.permutation(len(state)):
    updated = 1 if fields[neuron] > 0 else -1
    delta = updated - state[neuron]
```

`permutation` выбирает случайный порядок обхода нейронов без повторений в одном проходе.
Для очередного нейрона по знаку его влияния выбирается +1 или −1.
`delta` показывает изменение: 0 — клетка прежняя, +2 — было −1 и стало +1, −2 — наоборот.

Если клетка изменилась, выполняются строки:

```python
state[neuron] = updated
fields += delta * WEIGHTS[:, neuron]
```

Первая сохраняет новое состояние клетки.
Вторая сразу обновляет её влияние на все остальные клетки. `WEIGHTS[:, neuron]` берёт столбец весов, связанный с этим нейроном.
Поэтому следующий нейрон уже учитывает изменения предыдущего.

Разница режимов: в синхронном все принимают решение по одной старой картинке, в асинхронном картинка изменяется прямо во время обхода.
Если целый проход ничего не поменял, восстановление завершено.

## 6. Портим ровно нужное количество пикселей

```python
noisy = pattern.copy()
count = round(len(pattern) * noise_percent / 100)
noisy[noise_rng.choice(len(pattern), count, replace=False)] *= -1
return noisy
```

`copy()` создаёт копию, чтобы не испортить запомненную букву.
`count` — сколько клеток надо поменять: для 100 пикселей и 30% шума это 30 клеток.
`choice(..., replace=False)` выбирает разные позиции без повторений, а `*= -1` меняет знак: +1 становится −1 и наоборот.

При 100% шума получится полный негатив буквы, а не случайный набор клеток.

## 7. Сравниваем два режима на одном входе

```python
noisy = corrupt(pattern, level, noise_rng)
sync = recall_sync(noisy)
asynchronous = recall_async(noisy, order_rng)
```

Создаётся одна испорченная буква `noisy`, и именно она подаётся обоим режимам.
Обе функции работают с копией входа, поэтому первый запуск не меняет картинку для второго.

Правильность проверяется так:

```python
correct += [np.array_equal(sync.state, pattern),
            np.array_equal(asynchronous.state, pattern)]
```

`array_equal` требует полного совпадения результата с исходной буквой: все 100 пикселей должны совпасть.
Совпадение добавляет единицу в счётчик успехов соответствующего режима.
Другая буква, негатив или ложный образ считаются ошибкой, даже если сеть пришла к устойчивому состоянию.

Для каждого из 12 уровней шума выполняется по 10 испытаний на каждую из трёх букв — всего 360 входов.
Расширенный опыт содержит по 200 испытаний — всего 7200 входов. Каждый вход проверяется двумя режимами.
Шум и порядок обхода имеют отдельные генераторы: число шагов восстановления не меняет последующие тестовые картинки.

## 8. Зачем нужна энергия

```python
def energy(state):
    return float(-0.5 * state @ WEIGHTS @ state)
```

Энергия — число, которое описывает согласованность текущего рисунка с весами сети.
Формула обычным текстом: `E = -0.5 * stateᵀ * WEIGHTS * state`.
При симметричных связях и нулевой диагонали асинхронное изменение одного нейрона не увеличивает энергию.

На графике энергия идёт вниз или остаётся прежней. Но это ещё не доказывает, что восстановлена нужная буква: минимум может соответствовать другому устойчивому рисунку.
Для синхронного режима такое монотонное снижение не предполагается.

## Какие результаты получены

Средняя точность по трём буквам в опыте на 200 испытаний:

| Шум | Синхронный режим | Асинхронный режим |
|---|---:|---:|
| 10–20% | 100% | 100% |
| 30% | 97,67% | 97,17% |
| 40% | 71,00% | 71,50% |
| 45% | 33,50% | 34,83% |
| 50% | 0% | 0,50% |
| 60–100% | 0% | 0% |

При 50% шума 15 из 600 синхронных запусков на этом уровне попали в цикл длины 2.
При полной инверсии вход является устойчивым негативом эталона. Поэтому сеть не возвращает исходную букву.
Оценка ёмкости по формуле задания равна примерно 9,31 образа, но устойчивость наших трёх букв проверяется отдельно, а не выводится только из этой оценки.

## Как сказать преподавателю

«Я записываю три буквы как векторы из +1 и −1. По правилу Хебба вычисляю связи между пикселями и обнуляю самосвязи. Потом инвертирую заданную часть клеток и смотрю, восстановится ли эталон. Сравниваю одновременное обновление всех нейронов и обновление по одному. Считаю точность, отслеживаю циклы и проверяю энергию. При малом шуме восстановление хорошее, около 50% точность резко падает».

## Короткие ответы

- **Почему нейронов 100?** По одному на каждый пиксель картинки 10×10.
- **Почему асинхронный режим не всегда лучше?** Порядок изменений может привести к другому минимуму; успех для каждого отдельного входа не гарантируется.
- **Почему устойчивое состояние бывает неправильным?** Кроме эталонов у сети есть негативы и ложные устойчивые образы.
- **Почему отдельная точка при большем шуме может быть лучше?** При малом числе испытаний заметен случайный разброс; поэтому добавлен опыт на 200 входах для каждой буквы и уровня.
- **Какая сложность?** Для P образов и n нейронов обучение O(P·n²), хранение весов O(n²), один синхронный шаг или полный асинхронный проход O(n²). I проходов требуют O(I·n²).
