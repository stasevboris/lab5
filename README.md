# ЛР5 — сеть Хопфилда

## Что решает работа

Нужно запомнить три первых буквы фамилии — С, Т, А — и восстанавливать их после инверсии части пикселей.
Каждая буква имеет размер 10 × 10: получается сеть из 100 нейронов.
Чёрный пиксель кодируется +1, белый — −1. Это ассоциативная память: искажённый образ должен прийти к одному из запомненных состояний.

## Обучение по правилу Хебба

`LETTERS` задаёт рисунки через `#` и точки. `PATTERNS` содержит три биполярных вектора.
Матрица связей вычисляется как `WEIGHTS = PATTERNS.T @ PATTERNS`, после чего диагональ обнуляется:

$$w_{ij}=\sum_{\mu=1}^{P}a_i^{\mu}a_j^{\mu},\quad i\ne j;\qquad w_{ii}=0.$$

У нейрона нет связи с самим собой. Матрица симметрична.
`activation()` возвращает +1 при положительном поле и −1 при нулевом или отрицательном.
Все три эталона проверяются на устойчивость: активация W·a должна вернуть сам a.
Итерационного подбора весов здесь нет: правило Хебба сразу вычисляет их из образов.

## Два режима восстановления

`recall_sync()` одновременно обновляет все нейроны по состоянию предыдущего шага.
Словарь `seen` хранит посещённые состояния, поэтому различаются неподвижная точка, цикл и достижение лимита.
Синхронное обновление может давать цикл длины 2.

`recall_async()` обновляет нейроны по одному в случайном порядке.
Следующий нейрон уже видит изменения предыдущих. Поле хранится в `fields`.
При изменении нейрона i на величину delta все поля корректируются как `fields += delta * WEIGHTS[:, i]`.
Это эквивалентно пересчёту скалярных произведений, но позволяет обновлять поля через один столбец матрицы.
После полного прохода без изменений состояние считается устойчивым.

Оба режима копируют входной вектор, поэтому один режим не изменяет тестовый образ для другого.

## Энергия и ошибки восстановления

`energy()` вычисляет:

$$E(s)=-\frac12s^TWs.$$

Для симметричных весов с нулевой диагональю энергия не возрастает при асинхронном обновлении.
При изменении одного нейрона она корректируется на −delta·hᵢ. В демонстрации это значение сверяется с прямым расчётом.
Для синхронных шагов монотонное снижение энергии не предполагается.

Уменьшение энергии не гарантирует восстановление нужной буквы: сеть может прийти к другой букве, негативу или ложному устойчивому образу.
`identify()` различает эти исходы. Успехом считается только точное совпадение с исходным эталоном.

## Как устроен эксперимент

`corrupt()` инвертирует ровно заданное число разных пикселей, выбранных без повторений.
При 100% получается полный негатив буквы, а не случайный рисунок.
`run_experiment()` проверяет уровни шума 10, 20, 30, 35, 40, 45, 50, 60, 70, 80, 90 и 100%.

Основной опыт содержит по 10 входов на букву и уровень, всего 360 входов. Расширенный — по 200, всего 7200.
Каждый вход проверяется обоими режимами. Генераторы шума и порядка обновления разделены, поэтому длительность асинхронного восстановления не меняет последующие тестовые входы.
Основной seed равен 16, расширенного опыта — 17, демонстрации — 41.
Шаг точности для одной буквы равен 10 процентным пунктам при 10 испытаниях и 0,5 пункта при 200.

## Какие результаты получены

Средняя точность по трём буквам в расширенном опыте:

| Шум | Синхронный режим | Асинхронный режим |
|---|---:|---:|
| 10–20% | 100% | 100% |
| 30% | 97,67% | 97,17% |
| 40% | 71,00% | 71,50% |
| 45% | 33,50% | 34,83% |
| 50% | 0% | 0,50% |
| 60–100% | 0% | 0% |

При 50% шума в синхронном режиме обнаружено 15 циклов длины 2 из 600 запусков на этом уровне.
При полной инверсии вход является устойчивым негативом эталона. Поэтому исходная буква не восстанавливается.
Это следует из симметрии модели без смещения, а не из ошибки внесения шума.

## Проверки и сложность

Проверяются симметрия весов, нулевая диагональ, устойчивость эталонов и их негативов, точное число инвертированных пикселей, число испытаний и невозрастание энергетической трассы.
Оценка ёмкости по формуле задания равна примерно 9,31 образа; это оценка, а устойчивость именно этих трёх образов подтверждается отдельной проверкой.
Для P эталонов и n нейронов обучение требует O(Pn²), память весов — O(n²).
Синхронный шаг и полный асинхронный проход требуют O(n²), I проходов — O(In²).
Хранение трассы энергии или посещённых синхронных состояний добавляет до O(In) памяти.

## Как рассказать на защите

«Я использую сеть Хопфилда как память трёх бинарных букв. Веса вычисляю по правилу Хебба и убираю самосвязи. Потом инвертирую заданный процент пикселей и сравниваю одновременное и последовательное обновление нейронов. Проверяю точное восстановление, циклы и энергию. При малом шуме сеть восстанавливает образы хорошо, около 50% точность резко падает, а полный негатив остаётся самостоятельным устойчивым состоянием».

## Что могут спросить

**Почему асинхронный режим не всегда лучше?** Результат зависит от входа, порядка обновления и того, в какой минимум энергии попала сеть; преимущество на каждом отдельном входе не гарантируется.

**Почему при большем шуме отдельная точка таблицы может оказаться лучше?** В конечном числе испытаний есть случайный разброс. Поэтому дополнительно выполнен опыт на 200 входах для каждой буквы и уровня.

**Чем сеть отличается от перцептрона?** Перцептрон выдаёт класс по линейной границе; сеть Хопфилда изменяет весь вектор состояния, восстанавливая образ через динамику связей.
